# Data

- `00-raw/llm_performance_leaderboard.csv`: model benchmark scores and token pricing from Artificial Analysis (https://artificialanalysis.ai). This is the dataset used in the final analysis.
- `00-raw/leaderboard.csv`: an earlier leaderboard export used during data exploration.
- `02-processed/`: cleaned data is written here when the notebook runs.

Raw files are never edited by hand; all cleaning happens in code.
